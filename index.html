Bernie — Linux repositories

Bernie prepares and runs your laser engraving and cutting jobs. These repositories install it and keep it up to date (x86_64 and ARM 64-bit, e.g. Raspberry Pi).

APT: Debian, Ubuntu, Linux Mint, Raspberry Pi OS

curl -fsSL https://beber666.github.io/bernie-releases/bernie.gpg | sudo tee /usr/share/keyrings/bernie.gpg > /dev/null
echo "deb [signed-by=/usr/share/keyrings/bernie.gpg] https://beber666.github.io/bernie-releases stable main" | sudo tee /etc/apt/sources.list.d/bernie.list
sudo apt update && sudo apt install bernie

Flatpak: any distribution

flatpak install --user https://beber666.github.io/bernie-releases/flatpak/bernie.flatpakref

Updates come with flatpak update or your software center.

USB lasers: your account must be a member of the dialout group (sudo usermod -aG dialout $USER, then log out and back in).

En français : ces commandes installent Bernie et ses mises à jour, par APT (Debian, Ubuntu, Linux Mint, Raspberry Pi OS) ou par Flatpak (toutes les distributions). Lasers en USB : votre compte doit faire partie du groupe dialout.
